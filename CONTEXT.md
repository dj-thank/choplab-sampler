# ChopLab domain glossary

## Chop

A bounded piece of source audio that can be assigned to a PAD and played as one sound.

## Beat loop

A Chop intended to repeat continuously from its end back to its start. Its repetition unit is the Chop itself, not a fixed interval on the sequencer grid.

## Loop boundary

The start and end points that define one complete Beat loop. A clean boundary avoids an audible gap, click, or unintended timing jump when playback returns to the start.

## Pattern placement

One or more positions on the beat timeline where a PAD is triggered. Pattern placement is separate from looping the Chop audio itself.

## Placement preset

A shortcut that creates regularly spaced Pattern placements, such as quarter-note, eighth-note, or sixteenth-note triggers.

## AI assist proposal

A reversible suggestion for improving a Beat loop, presented for comparison before it changes the project.

## Drum kit

A named set of original drum one-shots assigned together to one PAD bank, with an optional beginner starter pattern. Built-in kits are generated by ChopLab and do not contain artist recordings.

## Recording session

The single active recording operation in ChopLab. A session is either a Source capture or a Vocal take; multiple recording sessions never overlap.

## Source capture

A microphone or device-audio recording that becomes a new Source when stopped. Source capture excludes ChopLab playback so an old PAD, loop, source, or scratch cannot contaminate the recording.

## Primary playback mode

The currently focused Source, selection preview, Beat loop, sequencer transport, or scratch voice. Starting one primary mode first stops the previous mode and its live voices, preventing accidental doubled playback. Normal performance PAD hits can still be layered deliberately after the mode starts.

## Vocal take

A microphone recording aligned by restarting the active Beat loop when recording begins. It is stored as a one-shot layer in BANK D and starts once with the Beat loop or offline export.

## Scratch gesture

Direct manipulation of one selected Chop with signed playback speed: rightward motion plays forward, leftward motion plays backward, and release stops the scratch voice.
