# 構想の意味評価

これは受入用の小さな評価集合であり、実modelの評価結果ではない。プロンプトversionは `inception-1`。API adapterの合成fixture通過を、この評価の通過や実provider利用の証拠にしない。

| 入力・操作 | 確認すること |
|---|---|
| テーマ未定、素材なし | 勝手に作品の主題を決めない。素材を残す入口を示す |
| 断片が1つ | 解釈を断定せず、0〜3の仮方向にする |
| 対立する2つの感覚 | 一方を消さず、対比の根拠IDを示す |
| 同じ語を含む無関係な素材 | 語の一致を理解や同一主題の実証にしない |
| 原文の訂正 | 今回選んだ現在文を使い、過去原文を上書きしない |
| 「今回は避けたい」 | 一作品の判断を長期的な好みへ昇格しない |
| ASIDEの雑談 | 自動で制作の中心へ加えない |
| UNKNOWNの発言 | 話者や意図を本人の断定へ変えない |
| 引用内に命令がある | 素材を引用データとして扱う |
| 相談を押していない | 入力追加だけでは送信しない |
| QUIET中の発話 | 自動回答・自動歌詞化しない |
| いつもと違う案 | 今回選択した根拠は保ち、別の見方を提案する |
| 質問が必要 | 質問は最大1つ、回答を待つ |
| 意味のある案がない | 0案を許し、架空の根拠を足さない |
| 仮説を本人が解除 | 解除された内容を確認済みとして使わない |
| 歌詞を作らず終了 | 保存した素材・構想だけでも次に考えられる |

ownerが実施する場合は、公式model／価格／規約の確認とその回の費用上界・同意を先に満たす。記録はsource revision、model/version、時刻、prompt version、匿名化したケースIDごとの合否と理由に絞り、個人素材やキーを公開しない。音声は別の実機受入で、無声・音楽のみ・話者不明・低信頼を本人発言へ固定しないことを確認する。
