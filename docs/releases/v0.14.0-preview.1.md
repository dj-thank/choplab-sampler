# ChopLab v0.14.0-preview.1

## Downloads

- Android: `ChopLab-v0.14.0-preview.1-debug.apk` and its `.sha256` file.
- iOS: `ChopLab-0.14.0-preview.1-ios-simulator.app.zip` and its `.sha256` file.

The iOS download is an unsigned iOS Simulator app. It is not an installable iPhone/iPad IPA and does not contain Apple signing credentials. Use a macOS machine with Xcode to install it into an available Simulator.

## Scope

- Android version `0.14.0` / version code `22`.
- Native iOS 16 SwiftUI + AVFoundation preview with local audio import, 16 PAD playback, normalized chop ranges, recording, and `ALL STOP`.
- No user audio, third-party sample, credential, signing key, or provisioning profile is included.

## Evidence boundary

GitHub Actions proves the checked-out source builds and packages the listed artifacts, and the SHA-256 files bind each download to its release bytes. This preview does not claim signed iOS device installation, Android/iOS physical-device audio quality, accessibility speech quality, or Human acceptance.
