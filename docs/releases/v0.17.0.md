# ChopLab v0.17.0

This preview makes the Windows build practical for everyday local use while preserving the same simple Android-origin production flow.

## Highlights

- Play the currently visible 4×4 PAD page from the PC keyboard: `1234 / QWER / ASDF / ZXCV`.
- Key-down owns one PAD voice and key-up releases that exact PAD; OS key-repeat and Ctrl/Alt/Meta shortcuts cannot create duplicate triggers.
- PAD input is disabled during source playback, recording, and project loading so keyboard performance cannot accidentally capture or replace audio.
- Native Windows File, Edit, and Transport menus expose WAV/project open, save, export, Undo/Redo, source playback, and ALL STOP shortcuts.
- PAD content badges (`DRM`, `VOX`, `LOOP`) no longer hide the keyboard key legend.
- A data-preserving user-local installer creates versioned immutable app bytes plus Start Menu and Desktop shortcuts without touching `%LOCALAPPDATA%\ChopLab\projects`.
- Dependency maintenance integrates actions/attest 4.2.2, CycloneDX 3.4.1, Kotlin 2.4.10, AGP 9.3.1, AndroidX Compose BOM 2026.08.00, Core KTX 1.19.0, and Gradle 9.7.1. Compile SDK moves to Android 17 / API 37 while minSdk remains 29 and targetSdk remains 36.

## Distribution boundary

The Windows asset is a self-contained unsigned app-image preview, not a code-signed MSI/MSIX. Android physical-device audio, Windows driver latency/audio quality, screen-reader speech, Spotify provider behavior, signed iOS device distribution, and human acceptance remain separate verification gates.
