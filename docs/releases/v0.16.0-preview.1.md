# ChopLab v0.16.0-preview.1

このpreviewは、制作を再開してからチョップをビートへ育てる流れをAndroid-origin UI全体でつなぎ直した、Windows / Android / iOS三平台の確認候補です。

## 今回の主な更新

- 最初の`入れる / CAPTURE`から`制作を開く / OPEN PROJECT`を選べます。
- 前回のautosaveを検証後、未編集starterはCAPTURE、Source制作はCHOP、Beat制作はBEATへ戻ります。
- 通常の`ビート / BEAT`をCHOPと同じ波形・BANK・PAD page・4×4 PAD演奏面へ統一しました。従来の16-step編集は`並べる詳細 / STEPS`に残しています。
- 本当に新しい制作だけ、オリジナル合成`DUSTY JAZZ` 16音とstarter patternをBANK Bへ準備します。復元／手動OPENした制作は上書きしません。
- スクラッチはpointer-downから開始し、微小動作dead zone、方向・倍率・playhead表示、120ms idle無音を追加しました。直前の有効なBeat loopまたはtransportがあれば、離した後に戻ります。

## 配布物

- Windows: `ChopLab-v0.16.0-preview.1-windows-app-image.zip` と、そのSHA-256およびEXE hash JSON。
- Android: `ChopLab-v0.16.0-preview.1-debug.apk` と、そのSHA-256ファイル。version `0.16.0` / version code `24`。
- iOS: `ChopLab-0.16.0-preview.1-ios-simulator.app.zip` と、そのSHA-256ファイル。iOS 16 SwiftUI + AVFoundation preview。

Windows app-imageは展開後に同梱の`ChopLab/ChopLab.exe`を起動します。iOS artifactは署名なしSimulator用であり、今回のAndroid-origin制作UI、starter drums、sequencer、scratchの完全な機能同等を主張しません。iPhone実機には利用者自身のApple Developer teamとXcode署名が必要です。

GitHub Actionsは各artifactを独立にbuild/testし、public-surface scanを通過した成果物だけをReleaseへ添付します。ユーザー／第三者音源、Spotify音声、OAuth token、署名鍵、provisioning profileは含みません。物理Android/iPhone音質、Bluetooth/route loss、TalkBack/VoiceOver読み上げ、Human acceptanceは別ゲートです。
