# ChopLab v0.15.0-preview.1

このpreviewは、Windows / Android / iOS の三平台を同じGitHub Releaseで確認できる配布候補です。

- Windows: `ChopLab-v0.15.0-preview.1-windows-app-image.zip` と、そのSHA-256およびEXE hash JSON。
- Android: `ChopLab-v0.15.0-preview.1-debug.apk` と、そのSHA-256ファイル。version `0.15.0` / version code `23`。
- iOS: `ChopLab-0.15.0-preview.1-ios-simulator.app.zip` と、そのSHA-256ファイル。iOS 16 SwiftUI + AVFoundation preview。

Windows app-imageは展開後に同梱の`ChopLab/ChopLab.exe`を起動します。iOS artifactは署名なしSimulator用です。iPhone実機には利用者自身のApple Developer teamとXcode署名が必要であり、GitHub Releaseは署名済みIPAを提供しません。

GitHub Actionsは各artifactを独立にbuild/testし、public-surface scanを通過した成果物だけをReleaseへ添付します。ユーザー音源、Spotify音声、OAuth token、署名鍵、provisioning profileは含みません。Spotify連携はOAuth/現在再生メタデータ・制御の境界に限ります。
