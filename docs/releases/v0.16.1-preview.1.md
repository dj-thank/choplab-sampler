# ChopLab v0.16.1-preview.1

このpreviewは、長い音源でも「ここから／ここまで」を手と数値の両方で素早く追い込める精密TRIM更新です。

## 今回の主な更新

- 音の入ったPADを長押しすると、AndroidとWindowsで同じ`切り位置 / TRIM`編集面を直接開きます。
- 波形を長押しすると、近い`START`または`END`を押した位置へ移動し、その周囲を最大1秒幅へ拡大します。
- `ここから / START`と`ここまで / END`を、ダイヤルと前／現在／次の時刻を持つ数値ホイールで調整できます。
- 数値ホイールは`1 FRAME`、`1 ms`、`10 ms`を切り替えられ、タッチの縦スワイプ、マウスホイール、アクセシビリティ操作に対応します。
- 既存の波形タップ、S/Eハンドル、PREVIEW、REVERT、Undo/Redoは維持し、境界は常に音源内かつ最小2 frameを保ちます。

## 配布物

- Windows: `ChopLab-v0.16.1-preview.1-windows-app-image.zip` と、そのSHA-256およびEXE hash JSON。
- Android: `ChopLab-v0.16.1-preview.1-debug.apk` と、そのSHA-256ファイル。version `0.16.1` / version code `25`。
- iOS: `ChopLab-0.16.1-preview.1-ios-simulator.app.zip` と、そのSHA-256ファイル。iOS 16 SwiftUI + AVFoundation preview。

Windows app-imageは展開後に同梱の`ChopLab/ChopLab.exe`を起動します。AndroidとWindowsは共有Compose UI／境界ロジックを使います。iOS artifactは署名なしSimulator用で、従来のnative範囲編集previewです。iPhone実機には利用者自身のApple Developer teamとXcode署名が必要です。

GitHub Actionsは各artifactを独立にbuild/testし、public-surface scanを通過した成果物だけをReleaseへ添付します。ユーザー／第三者音源、Spotify音声、OAuth token、署名鍵、provisioning profileは含みません。物理Android/iPhoneでの触感・音質、TalkBack/VoiceOver読み上げ、Human acceptanceは別ゲートです。
